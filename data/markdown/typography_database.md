### ✍️ 1.3 Typography Database (Complete 50 Archetypes)

[A] Font Pairings & Concept Archetypes (คลังการจับคู่ฟอนต์และมู้ดเรื่องสะท้อนอารมณ์ 50 สไตล์)

#### 🏛️ [A1 - A5] Historical, Royalty & Academic (สายคลาสสิก, ประวัติศาสตร์, ความขลัง)
*   **A1. Eternal Serif (Royal / Gothic / Vintage)**
    *   Thai: Noto Serif Thai (มีหัว, สุภาพ, คลาสสิก)
    *   English: Cinzel / Playfair Display / Sorts Mill Goudy
    *   Vibe: ประวัติศาสตร์, โบราณกาล, ราชวงศ์, แวมไพร์สายเลือดบริสุทธิ์, มหาวิทยาลัยเวทมนตร์
*   **A2. Dark Academia (Forbidden Library / Secret Society)**
    *   Thai: Chonburi (มีหัวสไตล์ไทยคลาสสิก เส้นหนาบางชัดเจน ให้มู้ดลึกลับแต่สง่า)
    *   English: EB Garamond / Almendra Display / Cardo
    *   Vibe: ห้องสมุดโบราณ, สมาคมลับในวิทยาลัย, บันทึกปกหนังเก่า, คดีปริศนากลางสายหมอก
*   **A3. Victorian Steampunk (Brass Gears / Steam Revolution)**
    *   Thai: Taviraj (มีหัวแบบกึ่งเหลี่ยมกึ่งมน ดูแข็งแกร่งและเป็นระเบียบ)
    *   English: Rye / Federant / Vollkorn
    *   Vibe: จักรกลไอน้ำ, ท่อทองเหลืองและฟันเฟือง, ลอนดอนยุคปฏิวัติอุตสาหกรรม, นักประดิษฐ์สติเฟื่อง
*   **A4. Mythological Epic (Gods / Angels / Sacred Ruins)**
    *   Thai: Srisakdi (ฟอนต์ไทยประดิษฐ์ อ่อนช้อย ลวดลายแปลกตาและขลัง)
    *   English: Uncial Antiqua / Eagle Lake / MedievalSharp
    *   Vibe: ตำนานเทพเจ้ากรีก, อารยธรรมโบราณที่ล่มสลาย, มหากาพย์สงครามศักดิ์สิทธิ์, บัญญัติทิวา
*   **A5. Oriental Heritage (Wuxia / Shinto / Dynasty)**
    *   Thai: Niramit (ฟอนต์มีหัวสไตล์เหลี่ยมสลัก ดูสง่า น่าเกรงขาม)
    *   English: Cinzel Decorative / Prata / Spectral
    *   Vibe: ยุทธภพกำลังภายใน, ศาลเจ้าโบราณ, การเมืองในวังหลวงตะวันออก, ขุนนางและซามูไร

#### 🌌 [A6 - A10] Cosmic, Sci-Fi & High-Tech (สายอนาคต, อวกาศ, เทคโนโลยี)

*   **A7. Brutalist Mainframe (Analog Horror / VHS / Lost Signal)**

    *   English: Rubik Glitch / VT323 / Major Mono Display
    *   Vibe: ม้วนเทปสยองขวัญที่ถูกทิ้งไว้, ปัญญาประดิษฐ์ที่แทรกซึมระบบ, จอคอมพิวเตอร์ยุค 80s ที่กะพริบในความมืด
*   **A8. Retro-Futurism & Vaporwave (City Pop / Neon Arcade / 80s Overdrive)**

    *   Vibe: ตู้เกมหยอดเหรียญ, แสงนีออนสะท้อนพื้นถนนเปียกฝน, เพลงแนว Lo-Fi Synth, รถซิ่งทะลุมิติ

    *   Vibe: เมืองลอยฟ้าพลังงานสะอาด, เทคโนโลยีกลมกลืนกับธรรมชาติ, พลังงานแสงอาทิตย์, ยูโทเปียอันเงียบสงบ
*   **A10. Cosmic Nihilism (Deep Space / Eldritch Sci-Fi / Black Hole)**

    *   English: Megrim / Syncopate / Quantico
    *   Vibe: ยานอวกาศที่เคว้งคว้างกลางสูญญากาศ, สิ่งมีชีวิตโบราณนอกอารยธรรม, มิติที่บิดเบี้ยวรอบหลุมดำ
