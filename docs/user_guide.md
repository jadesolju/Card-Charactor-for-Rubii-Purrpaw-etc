# 📖 คู่มือการใช้งาน: Rubii Card Architect v2.2.7 (User Manual)

## ❓ เครื่องมือนี้คืออะไร? (What is it?)

**Rubii Card Architect** คือ ปัญญาประดิษฐ์ (AI) ผู้ช่วยออกแบบหน้าเว็บการ์ดตัวละครสำหรับโทรศัพท์มือถือ โดยที่คุณไม่จำเป็นต้องมีความรู้เรื่องโค้ด HTML/CSS หรือการเขียนโปรแกรมใดๆ เลยแม้แต่น้อย
> 💡 *เพียงแค่ป้อนพล็อตเรื่องสั้นๆ หรือข้อมูลตัวละคร AI จะวิเคราะห์โทนเรื่องและสร้างโค้ดการ์ดเรืองแสงที่สวยงาม โหลดไว และใช้งานได้จริงทันที*

---

## ⚡ วิธีใช้งานเบื้องต้น (Quick Start)

### 1. โหมดด่วนคำตอบเดียว (`/turbo` หรือ `/express`)
หากคุณต้องการให้ AI จัดการให้ทุกอย่างตั้งแต่ต้นจนจบในข้อความเดียว ให้พิมพ์คำสั่ง `/turbo` ตามด้วยข้อมูลตัวละคร:

```text
/turbo
ชื่อตัวละคร: Seraphina Blight
แนวเรื่อง: Dark Romance / Gothic แวมไพร์สาวในคฤหาสน์เก่า
นิสัย: สุขุม เงียบขรึม มีบาดแผลในใจในอดีต
```

**สิ่งที่ AI จะส่งกลับมาทันที:**
1. **Character Dossier:** สรุปย่อประวัติตัวละครสั้นกระชับ (ไม่เกิน 3 บรรทัดต่อส่วน)
2. **Design Blueprint:** พิมพ์เขียวธีมสี ฟอนต์ และเอฟเฟกต์ที่เลือกใช้
3. **Production Code (Minified HTML/CSS):** โค้ดสำเร็จรูปที่พร้อมคัดลอกไปแปะในช่อง Custom Code ของแอป Rubii

## 🕹️ คำสั่งลัดควบคุม AI (Slash Commands Reference)

| คำสั่ง | ความหมายและจังหวะการใช้งาน |
| :--- | :--- |
| **`/turbo`** | **ทางลัดสูงสุด:** วิเคราะห์ -> แมตช์ธีมสี -> กางพิมพ์เขียว -> คายโค้ด Minified ทันทีใน 1 Turn |
| **`/express`** | **โหมดด่วน:** สรุปภาพรวมคอนเซปต์และพิมพ์เขียวดีไซน์ทันที |
| **`/recommend_theme`** | ให้ AI สวมบทบาทดีไซเนอร์ใหญ่ สุ่มแมตช์ธีมที่ดีที่สุดให้เข้ากับเนื้อเรื่องตัวละคร |
| **`/force_color`** | สั่งสลับเฉพาะโทนสีเรืองแสงใหม่ โดย**ล็อกเลย์เอาต์เดิมไว้ 100%** |
| **`/adjust_layout`** | สั่งปรับเปลี่ยนตำแหน่งกล่องข้อความและแท็บ โดย**ล็อกสีและฟอนต์เดิมไว้** |
| **`/show_score`** | แสดงตารางการประเมินคะแนนความสวยงาม ความเสถียร และ UX บนมือถือ |
| **`/start_inquiry`** | รีเซ็ตระบบเพื่อเริ่มกระบวนการสัมภาษณ์เลือก Moodboard แบบทีละสเต็ป |
| **`/generate_theme`** | คำสั่งสุดท้ายเพื่อสั่งให้ AI คายโค้ด Minified HTML/CSS สำเร็จรูป |

## 📱 กฎเกณฑ์ทางเทคนิคที่ผู้ใช้มั่นใจได้ (Quality Guarantees)
1. **Zero-JS 100%:** ไม่มี JavaScript แอบแฝง ปลอดภัย ไม่โดนระบบแอปบล็อก
2. **Mobile First:** ขนาดจอไม่เกิน `440px` ตัวอักษรหด-ขยายตามหน้าจออัตโนมัติด้วย `clamp()`
3. **Copyable Text:** ลากคลุมคัดลอกชื่อและเนื้อเรื่องบนมือถือได้จริง ไม่ใช้รูปภาพทับข้อความ
4. **Transparent & Glowing Frame:** พื้นหลังโปร่งใสเน้นเส้นขอบเรืองแสง เข้าได้กับทุกวอลเปเปอร์
